# Emoji Storage

Hide files as emoji.

## What it does
encode: Encodes the given file using a list of Emojis found in Emojibet.java
decode: does the above thing the other way around :)


Build and run: `./build.sh encode|decode <input> <output>`

input and output should both be files


## Example
`Hello World :)`

->

`😎🤙👾😂👾👀👾👀👾✅😭🔥😂🧨👾✅🧨😭👾👀👾😎😭🔥🤯😀😭😫🔥😀`

->

`Hello World :)`
